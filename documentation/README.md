# Documentation Folder

This folder contains documentation of recent changes made to the project.

## Files

- `changes_since_main.txt`: All code changes made since the last commit on the main branch, generated using `git diff origin/main..HEAD`.

## Process

1. Created the `documentation` folder in the project root.
2. Saved a summary of all code changes since the last main branch commit.

No uncommitted changes were detected at the time of documentation.
